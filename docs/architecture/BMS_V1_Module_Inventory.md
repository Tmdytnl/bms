# BMS V1 模块清单

文档状态：BMS V1 BSP/DRV/FML/APL 分层基线；按当前 production source 更新。

本表描述模块职责、调用上下文、安全相关性和验证入口。`docs/reference/` 与 `docs/FreeRTOS/` 是上游参考输入；生产集成入口是 `firmware/Project/Keil/BMS_V1.uvprojx`。

## 未发现的集成问题

- Keil production target 的项目自有源码只来自 `firmware/BSP`、`DRV`、`FML`、`APL`、`Config` 与 `User`；Git/Keil gate 会拒绝旧 `firmware/App`、`firmware/Driver` production source 复活。
- CAN protocol 与 persistence algorithm 分别位于 `firmware/FML/Communication`、`firmware/FML/Storage`，不再使用旧 `Protocol/Service` 混合目录表述。
- `BMS_Protect_SetXreadyRecoveryHook()` 是为冻结的 lower-phase regression 保留的兼容 seam；production 未安装该 hook，当前 coordinator 走 generation/revision authorization path。
- 阶段 milestone 报告保留；当前 release status 以 `deliverables/release/BMS_V1_Release_Baseline.md` 为准。

## 维护规则

新增模块时必须同步回答四个问题：谁写、在哪个上下文写、失败时是什么语义、哪条测试/构建证据覆盖。任何新的 SYS_CTRL2、CELLBAL、SYS_STAT W1C、IWDG feed 或 persistence page writer 都需要先检查冻结所有权，不得仅在此表中“补一行”来改变架构。
